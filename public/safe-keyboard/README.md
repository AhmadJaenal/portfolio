# Safe Keyboard screenshots

These files feed the homepage carousel and the `/portfolio/safe-keyboard`
gallery. To swap a screenshot, keep the same file name (or update the paths in
`src/components/home/HeroCarousel.jsx` and `src/data/projects.js`).

| File                            | Screen            | Indonesian label       |
| ------------------------------- | ----------------- | ---------------------- |
| `frame_blockedword_screen.png`  | Blocked Words     | Kata Diblokir          |
| `frame_pin_screen.png`          | Parent Mode       | Mode Orang Tua         |
| `frame_keyboard_screen.png`     | Live Filtering    | (filter saat mengetik) |
| `frame_setting_screen.png`      | Keyboard Settings | Pengaturan Keyboard    |

Slide names and captions are defined in `src/components/home/HeroCarousel.jsx`.
